## 1일차
과정소개

학습 리포지토리 생성

- 마크다운 기본문법 학습
  1. 제목
    ```markdown
    # 제목1
    ## 제목2
    ### 제목3
    #### 제목4
    ##### 제목5
    ###### 제목6
    <!-- 주석(HTML주석 동일) -->
    ```

  2. 목록
    ```markdown
    - 목록
    * 목록
    1. 숫자목록
    2. 숫자목록
    ```
    
  3. 링크, 이미지
 
    ```markdown
    [네이버](https://naver.com)
    
    ![이미지](이미지URL)

    ## 사이즈 조절 이미지
    <img src="이미지URL" width="500">
    ```

  4. 가로줄

    ```markdown
    ---
    ```

  ---
  5. 코드블럭
    - 소스코드를 작성할 때 코드하이라이팅, 영역표시 때 사용
    - 백틱(`)을 세번 후 표시언어를 입력 또는 한번(인라인 코드블럭)
    ```python
    print('Hellow, Python!')
    ```
    - 일반적인 문장에서 한 단어를 강조하고 싶을때 `인라인 코드블럭`을 사용

  6. 강조 및 밑줄
     ```markdown
     **, ~~, __, htnl u 태그 사용, i 이탤릭 사용
     ```
     - 문장을 작성할 시 **강조**, ~~취소선~~, __강조2__, <u>밑줄</u>, <i>이탤릭</i> 을 사용 할 수 있습니다.
